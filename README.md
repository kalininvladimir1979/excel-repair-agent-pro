# Ремонтное бюро

Локальный AI-агент для учебной мастерской. Оператор пишет команды по-русски, а заявки хранятся в книге Excel. Интерфейс включает чат, реестр, журнал вызовов MCP и переключатель между тёмной и светлой темами.

## Запуск

Нужны Node.js 22, npm и [uv с командой uvx](https://docs.astral.sh/uv/getting-started/installation/). Первый запуск Excel MCP загружает закреплённую версию пакета и её зависимости. Для чата нужен ключ проекта OpenAI с доступом к Responses API и выбранной модели.

```bash
git clone https://github.com/kalininvladimir1979/excel-repair-agent-pro.git
cd excel-repair-agent-pro
npm ci
npm run init:workbook
npm start
```

Откройте [рабочий экран](http://127.0.0.1:3099/) и задайте ключ OpenAI в [админке](http://127.0.0.1:3099/adminvk). В [консоли разработчика](http://127.0.0.1:3099/dev) можно выбрать модель Responses API и проверить каталог MCP и чтение книги. По умолчанию выбрана `gpt-6-luna`.

Ключ из админки и модель из консоли имеют приоритет над переменными окружения. Для настройки через окружение скопируйте `.env.example` в `.env` и заполните `OPENAI_API_KEY` и, при необходимости, `OPENAI_MODEL`. По умолчанию используется порт `3099`. Если `uvx` находится вне `PATH`, задайте `UVX_BIN` через окружение или `.env`.

`npm run init:workbook` создаёт `data/requests.xlsx` через MCP. Повторная команда откажется перезаписывать рабочую книгу. Если инициализация оборвалась, сообщение укажет путь к файлу. Осмотрите книгу и переместите её вручную, если она создана частично. Чистый образец `example/requests.xlsx` содержит только вымышленные заявки №101–103 на листе «Заявки».

## Как работает агент

[Excel MCP Server 2.3.2](https://github.com/haris-musa/excel-mcp-server/releases/tag/v2.3.2) поддерживает локальные книги, чтение по страницам и точечную запись ячеек. Официальный TypeScript SDK MCP запускает готовый сервер как дочерний процесс и обменивается с ним сообщениями через stdio.

```text
uvx excel-mcp-server==2.3.2 stdio --allow-dir <абсолютный путь к каталогу книги>
```

Express передаёт модели через [Responses API](https://developers.openai.com/api/docs/guides/function-calling) три прикладные функции. Модель выбирает функцию и аргументы, затем приложение валидирует аргументы и передаёт результат обратно через `function_call_output`. Путь, лист и диапазоны определяет код. Чат уточняет недостающие поля, черновик сохраняется в сессии браузера.

- **Добавление.** `create_request` читает актуальную книгу через `read_range`, вычисляет максимальный ID + 1 и записывает строку после последней занятой через `write_range`. Контрольное чтение сверяет четыре ячейки. Статус новой заявки — «Новый».
- **Смена статуса.** `prepare_status_change` ищет по ID или имени. При нескольких совпадениях запрашивает ID. При подтверждении приложение повторно находит заявку по ID, сравнивает содержимое с предпросмотром и пишет одну ячейку столбца D. Если строка изменилась, требуется новый предпросмотр. Подтверждение одноразовое и привязано к сессии.
- **Список.** `list_requests` заново читает книгу, продолжает по `next_range` и фильтрует по одному из трёх допустимых статусов. Ответ показывает ID найденных заявок и точное количество.
- **Инициализация.** `create_workbook` создаёт книгу с нужным листом. Затем приложение записывает и считывает исходный диапазон A1:D4. [Схемы инструментов MCP](https://github.com/haris-musa/excel-mcp-server/blob/v2.3.2/TOOLS.md).

Приложение слушает `127.0.0.1` и рассчитано на одного локального оператора. Рабочая книга и серверные настройки лежат в `data/`. Сессии, черновики, подтверждения и результаты повторных отправок хранятся в памяти процесса. Запускайте один экземпляр приложения для рабочей книги. При подтверждении или повторе отправки в пределах той же сессии приложение возвращает сохранённый результат. Не редактируйте книгу в табличном редакторе одновременно с записью агента. Используйте вымышленные данные. Ключ используется сервером для запросов к OpenAI, а API настроек отдаёт только источник ключа. Текст команд и фактические результаты прикладных функций обрабатываются OpenAI.

| HTTP | Операция |
| --- | --- |
| `GET /api/requests` | Текущие строки и журнал чтения |
| `POST /api/chat` | `{ message, submissionId }` с UUID. Ответ, результаты поиска или карточка подтверждения |
| `POST /api/status-confirmations/:id` | `{ action: "confirm" }` или `{ action: "cancel" }` |

В раскрываемом журнале «Вызовы MCP» видны имена инструментов, аргументы, результаты и ошибки в порядке вызова. Если результат записи неизвестен, приложение сначала перечитывает целевой диапазон и сообщает об успехе только после сверки.

## Проверка задания

Проводите сценарии по порядку на свежей рабочей книге.

| Команда | Ожидаемый результат |
| --- | --- |
| «Добавь заявку от Анны Смирновой: ноутбук сильно тормозит» | В A5:D5 появляется №104 со статусом «Новый». В журнале видны чтение, запись и контрольное чтение. |
| «Измени статус заявки Анны Смирновой на “В работе”» | До подтверждения D5 содержит «Новый». После нажатия «Подтвердить» меняется только D5. |
| «Покажи все заявки со статусом “В работе”» | Показаны №102 и №104. Количество равно двум. |
| «Измени статус заявки №999 на “Готово”» | Агент сообщает, что заявки нет. Записи через MCP нет. |
| «Добавь новую заявку от Дмитрия» | Агент спрашивает о проблеме. После ответа «После включения чёрный экран» появляется заявка №105 с клиентом «Дмитрий». |

Проверьте также отмену и устаревшее подтверждение. Если изменить исходную строку между предпросмотром и подтверждением, приложение запросит новую команду. После ручной правки используйте «Обновить». При недоступном MCP реестр показывает ошибку чтения.

```bash
npm test
```

Автоматический прогон выполняет HTTP-сценарии через настоящий Excel MCP и заменяет ответы OpenAI тестовыми. Каждый прогон использует временную копию чистого образца. Для первых пяти сценариев с реальной моделью настройте ключ в админке или в `.env` и выполните следующее.

```bash
REPAIR_TEST_OPENAI=1 node --env-file-if-exists=.env --test
```

Чтобы сохранить изменённую тестовую книгу для сверки в Excel или LibreOffice, задайте также `REPAIR_KEEP_TEST_BOOK=1`. Путь к книге выведет тест.
